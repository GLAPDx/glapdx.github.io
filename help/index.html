What is GLAPDx?

GLAPDx is a tool for designing LAMP (Loop-mediated isothermal AMPlification) primer sets. It finds primers that amplify a set of target genomes while avoiding amplification of background genomes.

Input files

All input files must be in FASTA format.

Index file

The complete genome database. Must contain the names and full sequences of all genomes relevant to the analysis - both targets and background.

>Genome_A
ACGTACGT...
>Genome_B
TTGCTTGC...

Reference genome

One of the target genomes. Must contain exactly one name and its full sequence. GLAPDx uses this genome to anchor the primer search region.

Target genomes

The other genomes to be amplified. This file contains names only (no sequences). All names must match entries in the index file.

>Genome_C
>Genome_D

Background genomes (optional)

Genomes that must not be amplified. Same format as Target genomes (names only). When set to Automatic, GLAPDx uses all index genomes that are not in the target set. When set to None, no specificity check is performed.

Parameters

Maximum mismatches in target
How many mismatches are allowed when checking if a primer binds to a target genome. Higher values improve sensitivity (primers work on more diverse targets) but may reduce specificity. Default: 0.
Maximum mismatches in background
How many mismatches are allowed when checking if a primer binds to a background genome. Higher values make specificity checks stricter (rejecting primers that partially match background). Default: 2.
Include loop primers
When enabled, GLAPDx designs LF and LB loop primers in addition to the six core LAMP primers. Loop primers accelerate the reaction and are recommended for most applications. Default: Yes.
Number of primers to generate
How many primer sets to return. GLAPDx stops once this many valid sets are found. Larger values take longer but give more options to choose from. Default: 10.

Tips

  • All genome names in the reference and target files must exactly match names in the index file.
  • If no primers are found, try increasing the mismatch thresholds.
  • Long runs can take several hours. Make sure that Prevent system from switching to standby is enabled. Note: some browsers disable this automatically when switching tabs.
  • Results and the full workspace (intermediate files, logs) can be saved after the run completes.
