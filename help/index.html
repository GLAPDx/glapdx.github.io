What is GLAPDx?

GLAPDx is a tool for designing LAMP (Loop-mediated isothermal AMPlification) primer sets. It finds primers that amplify a set of target genomes while avoiding amplification of background genomes.

Input files

All input files must be in FASTA format. Sequences should be defined only using canonical bases (A, C, G, T). In particular, U’s should be converted to T’s beforehand.

Target Genomes

All genomes to amplify. Must contain names and full sequences for every target genome, including the reference genome. The reference genome is then selected from a dropdown and defaults to the first genome in the file.

>Genome_A
ACGTACGT...
>Genome_B
TTGCTTGC...

Background Genomes (optional)

Genomes that must not be amplified. Must contain names and full sequences. Must not overlap with the target genomes. Leave empty for no background check.

Parameters

Maximum allowed mismatches against target
How many mismatches are allowed when checking if a primer binds to a target genome. Higher values improve sensitivity (primers work on more diverse targets) but may reduce specificity. Default: 0.
Minimum required mismatches against background
The minimum number of mismatches a primer must have against a background genome to be considered non-amplifying. Higher values yield more specific primer sets but accept fewer candidates. Default: 3.
Include loop primers
When enabled, GLAPDx designs LF and LB loop primers in addition to the six core LAMP primers. Loop primers accelerate the reaction and are recommended for most applications. Default: Yes.
Number of primers to generate
How many primer sets to return. GLAPDx stops once this many valid sets are found. Larger values take longer but give more options to choose from. Default: 10.

Preventing system standby

GLAPDx runs entirely in your browser and some designs can take several hours to complete. If your system goes to sleep or the screen turns off, the browser may suspend the computation, causing the run to stall or fail.

For long runs, a native application that prevents sleep is more reliable than the browser API:

Windows
PowerToys Awake
macOS
Run caffeinate -d in Terminal while the analysis is running, or use Amphetamine from the App Store.
Linux
Run caffeinate -d in Terminal while the analysis is running, see caffeinate(1).

Tips

  • Genome names in the background file must not overlap with names in the target genomes file.
  • If no primers are found, try increasing the mismatch thresholds.
  • Results and the full workspace (intermediate files, logs) can be saved after the run completes.
