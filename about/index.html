What is GLAPDx?

GLAPDx is a tool for designing LAMP (Loop-mediated isothermal AMPlification) primer sets. It finds primers that amplify a set of target genomes while avoiding amplification of background genomes. GLAPDx is an independent service built upon GLAPD. We are not officially affiliated with or endorsed by the GLAPD project.
